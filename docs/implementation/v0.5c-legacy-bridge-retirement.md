# Personal OS v0.5C — Legacy Bridge Retirement

Date: 2026-09-06

## Objective

Retire the runtime synchronization bridge that copied legacy browser `localStorage` state for Tasks/Projects/Decisions into Supabase during authentication bootstrap.

The canonical path is now:

```text
UI module
→ canonical repository
→ Supabase client
→ RLS / workspace boundary
→ PostgreSQL
```

## Change

`AuthGate.tsx` no longer imports or calls:

- `hydrateCoreStore()`
- `watchCoreStore()`

Authentication bootstrap now resolves only:

- current Supabase session;
- application profile;
- active workspace membership;
- workspace metadata;
- platform-admin status.

This prevents a legacy browser store from silently overwriting or recreating canonical records after the new CRUD surfaces have been adopted.

## Compatibility note

`core-cloud-store.ts` is retained temporarily as historical compatibility code but is no longer part of the authenticated runtime path. It may be removed entirely after all remaining legacy dashboard sections have migrated or been retired.

The old main dashboard may still keep prototype state in browser storage for presentation-only sections. That state is not canonical and should not be promoted back into Supabase through automatic polling.

## Risk addressed

Keeping two active sources of truth creates risks such as:

- stale browser data overwriting cloud data;
- archived records reappearing;
- deletion/archive semantics diverging;
- duplicate records;
- different devices presenting inconsistent state.

The bridge retirement removes that automatic conflict path.

## Validation

Required after deployment:

1. login still resolves profile/workspace correctly;
2. `/organizar/` loads canonical Goals/Projects/Tasks;
3. CRUD changes survive refresh and device/browser changes;
4. no authentication bootstrap error references the old bridge;
5. canonical records are not recreated from stale browser state.

## Next

Continue migrating/retiring browser-only prototype modules before the AI Copilot can be allowed to reason over the whole Personal OS state.
