## Product rule

These documents are **inspiration and planning frameworks**, not a global task checklist.

The Copilot must always adapt suggestions to:

- what the user actually wants;
- current state;
- time;
- money;
- constraints;
- preferences;
- risks;
- definition of success.

## Implementation intent

The eventual dedicated gamification area should present:

```text
Dreams
Active Journeys
Current Chapter
Missions
Next Best Action
Capabilities Unlocked
Milestones
Life Resources
Trajectory
```

Canonical state remains in the Personal OS domain model (Goals, Routes, Route Steps, Projects, Tasks, Routines, Events, Decisions, Metrics). The gamification experience is a presentation/progression layer over real data, not a parallel fake-points database.
