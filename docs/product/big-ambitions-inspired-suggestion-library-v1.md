# Personal OS — Big Ambitions-Inspired Suggestion Library v1

Date: 2026-09-07

## Purpose

This document turns the Big Ambitions research into a **suggestion library** for Personal OS.

These are not predefined obligations. They are examples the Copilot can use when a user's situation makes them relevant.

The AI should never say:

> "Everyone should complete this ladder."

It should say something closer to:

> "Based on what you want and your current state, these are the milestones that seem useful."

The library is intentionally broad so the same progression system can support personal life, learning, work, entrepreneurship, finances, home, leisure and long-term dreams.

---

# 1. Entity language

## Dream

A desired future state that may not yet be actionable.

Examples:
- own a home;
- have a profitable business;
- learn a profession;
- travel abroad;
- buy a motorcycle;
- have more time freedom;
- live with less financial stress.

## Goal

A defined outcome with a success condition.

Example:

```text
Dream: have my own motorcycle
Goal: acquire a motorcycle I can sustainably afford by December
```

## Journey

The complete route from current state to goal.

## Chapter

A meaningful phase of the journey.

## Mission

A result-oriented step that unlocks something or advances a chapter.

## Project

A multi-step body of work that produces an outcome.

## Task

A concrete action.

## Routine

A repeatable behavior that maintains or compounds progress.

## Milestone

A meaningful intermediate proof.

## Capability unlock

Something the user can now do that was not realistically possible before.

# 22. AI behavior when proposing suggestions

The Copilot should use this library as inspiration, not as a static recommendation engine.

## Step 1 — classify the statement

Examples:

```text
"Quero comprar uma moto" → acquire / mobility
"Quero consertar celulares" → learn + career/business
"Quero melhorar minha empresa" → improve / business
"Estou endividado" → stabilize / financial
"Quero viajar para o Japão" → experience / financial/logistics
```

## Step 2 — understand current state

Ask only what materially changes the route.

Possible dimensions:

- current capability;
- money;
- deadline;
- available time;
- existing assets;
- dependencies;
- constraints;
- preferences;
- reason/motivation;
- success definition.

## Step 3 — offer a journey

```text
Dream / intention
→ success definition
→ route options
→ recommended chapters
→ missions
→ milestones
→ first next action
```

## Step 4 — user approval

The AI does not silently create persistent plans.

## Step 5 — track evidence

Completion should reference real evidence when reasonable.

Examples:

- bank balance updated;
- document uploaded;
- customer completed;
- course/certificate recorded;
- asset purchased;
- task confirmed by user;
- metric imported from a connected source.

## Step 6 — adapt

The route can change if:

- deadline changes;
- money changes;
- user changes objective;
- task remains blocked;
- new opportunity appears;
- prerequisite is completed;
- risk increases;
- evidence contradicts an assumption.

## Visual inspiration from games without copying game UI

Useful patterns:

- roadmap / progression tree;
- locked nodes with explicit prerequisite;
- chapter completion;
- milestone cards;
- visual capability unlocks;
- optional achievement collection;

- arbitrary coins;

- daily guilt streaks;
- leaderboards comparing private lives.

# 24. Seed examples for the future suggestion engine

When the user has no active journey, Personal OS may offer optional prompts such as:

### Stability

- "Existe alguma coisa recorrente que está sempre virando emergência?"
- "Você quer montar uma reserva mínima para imprevistos?"
- "Alguma rotina de casa, contas ou compromissos está consumindo atenção demais?"

### Career / skill

- "Existe uma habilidade que você gostaria de transformar em renda?"
- "Quer criar um caminho para uma nova profissão?"
- "Há algum curso que você quer transformar em capacidade prática, não só concluir?"

### Business

- "Você quer conquistar o primeiro cliente de uma nova oferta?"
- "Quer reduzir sua dependência operacional de uma tarefa repetitiva?"
- "Quer melhorar margem, prazo ou capacidade de algum serviço?"

### Finance

- "Quer construir uma reserva?"
- "Quer planejar uma compra grande sem comprometer sua estabilidade?"
- "Quer criar um plano para uma dívida específica?"

### Life / experience

- "Tem alguma viagem, hobby ou experiência que você quer tirar do campo do 'um dia'?"
- "Existe algo que você quer aprender só porque é importante para você?"

These prompts should never be spammed. They should appear only when the user wants inspiration or the system detects an appropriate review moment.

# 25. Definition of success for this feature

The gamification layer is successful when a user can say:

> "I told the system what I wanted, it understood where I was, it gave me a believable path, it showed what was blocking me, and over time I could actually see my life changing."

Not merely:

> "I checked many boxes and gained points."
