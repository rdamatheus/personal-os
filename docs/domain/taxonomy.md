# Taxonomy Strategy

Taxonomies are hierarchical, configurable and namespaced.

## Example namespaces
- Life Area
- Consumable
- Routine Type
- Work
- Finance
- Learning
- Relationship
- Environment
- Emotional State
- Metric

## Example consumable hierarchy
```text
Consumable
├── Medication
│   ├── Stimulant
│   ├── Antidepressant
│   └── Analgesic
├── Substance
│   ├── Cannabis
│   ├── Alcohol
│   ├── Nicotine
│   └── Caffeine
├── Nutrition
│   ├── Meal
│   ├── Sugar
│   └── Water
└── Supplement
```

## Rules
Categories are configurable. Items reference categories; events reference items. Hierarchy organizes semantics but does not imply biological or behavioral equivalence. Sensitive categories can define privacy and display policies.
